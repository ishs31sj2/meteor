# 면학 불참 계획 관리자 (MyeonhakCalendar) v5

## 🎯 주요 기능 (v5 업데이트)

### 1. 면학 불참 사유 기입 기능
- **8 면, 1 면, 2 면** 각각에 대해 불참 사유를 상세히 기록할 수 있습니다.
- 달력에서 날짜 선택 후 "상세 편집" 버튼을 클릭하면 사유 입력 창이 나타납니다.
- 불참 사유는 달력 화면과 바탕화면 메모에 자동으로 표시됩니다.

### 2. 면불 ToDo 관리 기능
- 각 날짜별로 **할 일 목록 (ToDo)**을 추가/수정/삭제할 수 있습니다.
- 더블클릭으로 완료 처리 가능 (완료 항목은 회색 표시).
- 상세 편집 창에서 편리하게 관리하세요.

### 3. 실시간 시계 동기화
- 상단에 현재 시간을 초단위로 업데이트하여 표시합니다.

### 4. 한국 공휴일 자동 연동
- `holidays` 라이브러리를 사용하여 매년 자동 업데이트되는 공휴일 정보를 제공합니다.
- 달력에 공휴일이 빨간색으로 표시되고 이름도 함께 표시됩니다.

### 5. 알람 기능
- 특정 시간에 팝업 알림과 경고음을 울려줍니다.

### 6. 바탕화면 메모 동기화
- 선택한 날짜의 면학 계획과 할 일 목록을 바탕화면의 텍스트 파일로 저장합니다.

## 🚀 Windows 에서 EXE 파일 생성 및 실행 방법

### 1 단계: 파일 준비
1. `myeonhak_calendar_v5.py` 와 `build_windows_v5.bat` 파일을 같은 폴더에 둡니다.
2. 두 파일을 Windows PC 로 복사합니다.

### 2 단계: 자동 빌드 스크립트 실행 (**중요**)
1. **`build_windows_v5.bat` 파일을 우클릭**합니다.
2. **"관리자 권한으로 실행"**을 선택합니다.
   - 일반 더블클릭 시 권한 오류가 발생할 수 있습니다.
3. 검은색 명령 프롬프트 창이 열리며 자동으로 다음 작업을 수행합니다:
   - Python 설치 확인
   - 필요한 패키지 (`holidays`, `pyinstaller`) 자동 설치
   - `MyeonhakCalendar.exe` 생성

### 3 단계: 프로그램 실행
- 빌드가 완료되면 `dist` 폴더가 생성됩니다.
- `dist\MyeonhakCalendar.exe` 를 더블클릭하여 프로그램을 실행합니다.

## ⚠️ 자주 발생하는 오류 및 해결 방법

### 오류 1: "'pyinstaller' 은 (는) 인식되지 않습니다..."
- **해결**: `build_windows_v5.bat` 을 **관리자 권한으로 실행**하세요. 스크립트가 자동으로 pyinstaller 를 설치합니다.

### 오류 2: "인코딩 오류" 또는 "알 수 없는 문자"
- **해결**: 배치 파일 (`bat`) 이 UTF-8 로 저장되어 있는지 확인하세요. 제공된 파일은 이미 UTF-8 로 저장되어 있습니다.

### 오류 3: "Python 이 없습니다"
- **해결**: [Python 공식 사이트](https://www.python.org/downloads/) 에서 최신 버전을 설치하세요. 설치 시 "Add Python to PATH" 체크박스를 꼭 선택하세요.

## 💡 사용 팁

1. **상세 편집 활용**: 달력의 날짜를 클릭하고 우측의 "상세 편집" 버튼을 눌러 면불 사유와 할 일을 한 번에 관리하세요.
2. **바탕화면 메모**: 중요한 날의 계획을 바탕화면에 저장하여 잊지 않도록 하세요.
3. **공휴일 확인**: 달력의 빨간색 표시를 통해 공휴일을 쉽게 확인할 수 있습니다.

## 📄 데이터 저장 위치
- 모든 데이터는 프로그램이 실행되는 폴더의 `myeonhak_data.json` 파일에 저장됩니다.
- 이 파일을 백업해두면 데이터를 안전하게 보관할 수 있습니다.
