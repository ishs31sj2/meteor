# 면학 불참 계획 관리자 (Ultimate v5) - Windows 설치 가이드

## 📦 다운로드 및 실행 방법

### 1 단계: 파일 준비
1. `MyeonhakCalendar_Final_v5.zip` 파일을 Windows PC 로 다운로드합니다.
2. 원하는 폴더 (예: `C:\Myeonhak`) 에 압축을 풉니다.

### 2 단계: 자동 빌드 스크립트 실행
압축을 푼 폴더에 다음 두 파일이 있어야 합니다:
- `myeonhak_final.py` (메인 프로그램)
- `setup_final.py` (자동 설치/빌드 스크립트)

**방법 A: Python 이 이미 설치된 경우**
1. 폴더에서 우클릭 → "터미널에서 열기" 또는 CMD 실행
2. 다음 명령어 입력:
   ```cmd
   python setup_final.py
   ```
3. 자동으로 패키지가 설치되고 EXE 파일이 생성됩니다.

**방법 B: Python 이 설치되지 않은 경우**
1. [Python 공식 사이트](https://www.python.org/downloads/) 에서 Python 3.8 이상 다운로드 및 설치
2. 설치 시 **"Add Python to PATH"** 체크박스를 반드시 선택하세요!
3. 위 방법 A 와 동일하게 진행

### 3 단계: 프로그램 실행
빌드가 완료되면 `dist` 폴더 안에 `MyeonhakCalendar.exe` 가 생성됩니다.
이 파일을 더블클릭하여 프로그램을 실행하세요!

## ✨ 주요 기능 (v5)

### 🗓️ 달력 기반 일정 관리
- **실시간 시계**: 상단에 현재 시간 표시 (초단위 업데이트)
- **한국 공휴일 자동 연동**: 매년 자동 업데이트되는 공휴일 정보 (빨간색 표시)
- **월간 뷰**: 직관적인 달력에서 날짜 선택

### 📚 면학 설정 (8 면/1 면/2 면)
- **면불 사유 입력**: 각 면학 시간에 대한 불참 사유를 상세히 기록
- **메모 기능**: 추가 메모 작성 가능
- **시각적 표시**: 
  - 8 면: 빨간색
  - 1 면: 민트색
  - 2 면: 노란색

### ✅ 할 일 (ToDo) 관리
- 날짜별 할 일 추가/삭제
- 더블클릭으로 완료 처리
- 완료 항목은 회색으로 표시

### ⏰ 알람 기능
- 원하는 시간에 팝업 알림 + 경고음

### 📝 바탕화면 동기화

## 🔧 문제 해결

### Q1. "python" 명령어를 인식하지 못합니다
**해결**: Python 설치 시 PATH 추가를 하지 않은 경우입니다.
- Python 을 재설치하면서 "Add Python to PATH"를 체크하세요.

### Q2. 패키지 설치가 실패합니다
**해결**: 인터넷 연결 상태를 확인하고, 다음 명령어로 수동 설치:
```cmd
pip install holidays pyinstaller
```

### Q3. EXE 파일이 생성되지 않습니다
**해결**: 관리자 권한으로 CMD 를 실행 후 수동으로 PyInstaller 실행:
```cmd
pyinstaller --onefile --windowed --name "MyeonhakCalendar" myeonhak_final.py
```
