==================================================
면학 불참 계획 관리 프로그램 (Myeonhak Calendar)
==================================================

[프로그램 소개]
이 프로그램은 학교의 8면, 1면, 2면 면학 시간에 대한 
불참 계획표 만들기와 날짜별 할 일 목록을 관리할 수 있는
달력 기반 UI 프로그램입니다.

[주요 기능]
- 주/월/년 뷰로 달력 확인
- 평일(월~금)에 8면, 1면, 2면 면학 계획 설정
- 주요 공휴일 및 시험 일정 등록
- 할 일 목록 관리
- 데이터 자동 저장

[실행 방법]
1. Windows 사용 시: MyeonhakCalendar.exe 실행
2. Linux/Mac 또는 Python 환경에서 직접 실행 시:
   python3 myeonhak_calendar.py

[데이터 저장 위치]
프로그램 실행 시 자동으로 data.json 파일이 생성되며,
모든 면학 계획과 할 일 정보가 저장됩니다.

[주의사항]
- .exe 파일은 Windows 환경에서만 실행 가능합니다.
- Linux/Mac에서는 Python 스크립트를 직접 실행하세요.
