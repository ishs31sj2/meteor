# 면학 불참 계획 관리자 - Windows 실행 파일 생성 가이드

## 📋 프로그램 소개
면학 불참 계획 관리자는 학교의 8면, 1면, 2면 면학 시간에 대한 불참 계획을 달력 UI 로 관리할 수 있는 프로그램입니다.

### 주요 기능
- 📅 **달력 뷰**: 월간 달력에서 날짜별 면학 계획 확인
- 📚 **면학 관리**: 8면, 1면, 2면 불참/참가 상태 등록 및 메모
- ✅ **할 일 목록**: 날짜별 할 일 추가, 완료 처리, 삭제
- 🎨 **모던 UI**: 다크 테마의 세련된 인터페이스
- 💾 **자동 저장**: 모든 데이터는 JSON 파일에 자동 저장

## 🚀 Windows 에서 실행 파일 (.exe) 만들기

### 방법 1: PyInstaller 사용 (권장)

1. **Python 설치**
   - Python 3.8 이상을 설치합니다 (https://www.python.org/downloads/)
   - 설치 시 "Add Python to PATH" 체크박스를 반드시 선택하세요!

2. **필요 패키지 설치**
   ```cmd
   pip install pyinstaller
   ```

3. **실행 파일 생성**
   ```cmd
   cd C:\경로\myeonhak_calendar_v2.py 가_있는_폴더
   pyinstaller --onefile --windowed --name "MyeonhakCalendar" --icon=NONE myeonhak_calendar_v2.py
   ```

4. **생성된 파일 확인**
   - `dist` 폴더 안에 `MyeonhakCalendar.exe` 파일이 생성됩니다
   - 이 파일을 더블클릭하면 프로그램이 실행됩니다

### 방법 2: spec 파일 사용 (고급 옵션)

더 많은 제어가 필요한 경우 `myeonhak.spec` 파일을 사용할 수 있습니다:

```cmd
pyinstaller myeonhak.spec
```

## 📦 배포용 ZIP 파일 만들기

1. 다음 파일들을 하나의 폴더에 모습니다:
   - `MyeonhakCalendar.exe` (dist 폴더에서)
   - `README.txt` (이 파일)

2. 폴더를 우클릭 → 보내기 → ZIP 압축 폴더

3. 생성된 ZIP 파일을 다른 Windows PC 에서:
   - ZIP 파일 해제
   - `MyeonhakCalendar.exe` 더블클릭

## ⚙️ 시스템 요구사항

- **OS**: Windows 7 이상 (Windows 10/11 권장)
- **Python**: 런타임 불필요 (실행 파일에 포함됨)
- **디스플레이**: 1280x720 이상 권장

## ❗ 주의사항

1. **데이터 백업**
   - 프로그램과 동일한 폴더에 `myeonhak_data.json` 파일이 생성됩니다
   - 이 파일에 모든 데이터가 저장되므로 중요하게 관리하세요
   - 백업 시 이 파일을 함께 복사하세요

2. **바이러스 백신**
   - 일부 백신 프로그램이 PyInstaller 로 만든 실행 파일을 오진할 수 있습니다
   - 이 경우 예외 처리하거나 소스 코드에서 직접 실행하세요

3. **관리자 권한**
   - 일반적으로 관리자 권한은 필요하지 않습니다
   - Program Files 에 설치하는 경우에만 관리자 권한 필요

## 🔧 문제 해결

### 프로그램이 실행되지 않음
- Windows Defender 또는 백신 프로그램이 차단했는지 확인
- `.exe` 파일을 우클릭 → 속성 → "차단 해제" 체크

### 한글이 깨짐
- Windows 지역 설정에서 "비 유니코드 프로그램용 언어"를 한국어로 설정

### 데이터가 저장되지 않음
- 프로그램 실행 폴더에 쓰기 권한이 있는지 확인
- 다른 폴더로 이동하여 실행해 보세요
